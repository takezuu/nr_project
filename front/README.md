Игра в лабиринт API
Веб-игра, в которой игрок перемещается по сгенерированному лабиринту, собирая предметы и стремясь к выходу. Игра использует FastAPI для взаимодействия с пользователем через API.

Особенности
Динамическое создание лабиринта с путями, предметами и финальным выходом.
Перемещение игрока и взаимодействие через API.
RESTful API на основе FastAPI.
Сбор предметов и условия для выхода.
Логирование и визуализация карты.

Технологии
FastAPI: Веб-фреймворк для создания API.
Pydantic: Валидация данных и управление настройками.
Starlette: Обработка статических файлов.
Random: Случайные позиции на карте и игроке.
API эндпоинты

GET /
Возвращает домашнюю страницу игры.
GET /favicon.ico
Возвращает favicon для игры.
GET /map
Возвращает текущую карту и позицию игрока.
GET /remap
Генерирует и возвращает новую карту. Требует, чтобы текущая игра была завершена.
POST /move
Перемещает игрока по карте в зависимости от указанных координат.

Тело запроса json

{
  "row": <int>,
  "col": <int>
}
Ответ
Новая позиция игрока.
Был ли сделан ход.
Завершена ли игра.
